4. Deterministic vs Non-Deterministic Control
   What they’re testing
   Do you understand real-time systems
   Deterministic
   Same input → same output at predictable time
   PLC scan cycles
   Real-time motion control

👉 Required for:

safety
motion
timing-critical systems
Non-deterministic
Timing not guaranteed
OS scheduling, networks, cloud systems

👉 OK for:

data logging
UI
analytics
Strong answer

“I keep time-critical control deterministic—PLC or real-time systems handle motion and safety. Non-deterministic systems like SCADA or cloud are used for monitoring, not control decisions.”

What NOT to say
“Everything runs fine on Ethernet”
(You must acknowledge latency/jitter)
